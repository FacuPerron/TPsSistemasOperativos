#  Trabajos Prácticos - Sistemas Operativos

Repositorio que contiene distintos trabajos prácticos realizados en la materia **Sistemas Operativos**, enfocados en conceptos fundamentales del funcionamiento de un sistema operativo y su interacción con el hardware y los procesos.

---

##  Descripción

A lo largo de estos trabajos se abordan temas clave como el uso de Linux, programación a bajo nivel mediante llamadas al sistema, comunicación entre procesos y manejo del sistema de archivos.

El objetivo principal es comprender cómo el sistema operativo gestiona recursos, procesos y archivos.

---

##  Contenido del repositorio

###  Inicios en Linux

* Uso de comandos básicos y avanzados
* Navegación por el sistema de archivos
* Manipulación de archivos y directorios
* Introducción a scripting en Bash

---

###  Llamadas al sistema

* Interacción directa con el sistema operativo
* Uso de syscalls para manejo de procesos y archivos
* Programación en C utilizando funciones del sistema

---

###  Comunicación entre procesos (IPC)

* Pipes (tuberías)
* Procesos padre-hijo
* Sincronización básica entre procesos

---

###  File System

* Manejo de archivos y directorios
* Operaciones de lectura y escritura
* Organización y estructura del sistema de archivos

---

##  Tecnologías utilizadas

* Lenguaje C
* Bash scripting
* Entorno Linux


## 📌 Notas

* Cada carpeta contiene un trabajo práctico independiente.
* Los ejercicios fueron realizados con fines académicos.
* Se recomienda ejecutar los programas en un entorno Linux o máquina virtual.
